# 物理形状查询

查询直接使用当前 Box2D 世界，不建立第二套碰撞几何。
调用前同步已生成、移动、重建和销毁的刚体，但不推进模拟帧。
因此只能在 load/init/update 使用，draw 和 ui_update 拒绝调用。
纯美术实体不参与；传感器参与，`solid=false`、category 或 mask 为 0 的形状不参与。
当前查询使用全 32 位 category/mask；每次调用的自定义过滤参数尚未提供。
单向平台按完整碰撞几何查询，不应用玩家下落穿透规则。

```lua
-- 矩形左上角、尺寸；可选角度为弧度，绕矩形中心旋转。
local ids = sc.physics.query(40, 50, 32, 16, math.pi / 4)

-- 世界坐标点列 + 圆角半径。1 点为圆，2 点为胶囊，3..8 点为凸多边形。
local circles = sc.physics.overlap({100, 80}, 12)
local capsules = sc.physics.overlap({100, 80, 100, 104}, 8)
local polygons = sc.physics.overlap({20, 20, 60, 20, 40, 50}, 0)

-- 平移向量，不是终点；返回最近命中或 nil。
local hit = sc.physics.sweep({100, 80}, 8, 200, 0)
if hit then
    -- hit.id / x / y / nx / ny / fraction
    -- fraction 为移动比例；id=0 表示地图地形或地图边界。
end
```

点列必须是普通稠密数字数组，无额外命名字段。坐标与平移分量为有限数
`-1e6..1e6`；半径 `0..4096`。圆和胶囊需要正半径，胶囊端点不能重合；
多边形顶点按边界环绕排列，必须通过 Box2D 凸包校验，不接受凹形或退化几何。
矩形尺寸非负；宽或高为零返回空数组，旋转后的点也必须在坐标范围内。
零尺寸矩形直接返回，不同步待处理刚体。参数不接受数字字符串，多余参数
（包括尾随 nil）报错；可选 angle 的 nil 与省略都表示 0。

重叠结果按运行时实体 ID 数值升序，复合形状同一实体只返回一次，地形合并为 ID 0。
查询结果缓存由物理世界持有，初始化时按实体容量加一个地形记录分配，后续查询
复用存储并返回 Lua 数组副本。不会因命中数量增加而隐式扩大结果容量。
同步本身沿用刚体创建/重建的分配行为；不声称整个 Box2D 查询链零分配。

扫掠返回最近命中：精确相同 fraction 时按 ID，再按命中点与法线排序，
避免宽相树遍历顺序决定结果。射线使用相同排序，但忽略起点的零距离接触；
形状扫掠保留起始重叠，返回 `fraction=0, nx=0, ny=0`，此时法线不能用于滑动响应。
接触采用 Box2D 容差，不是像素严格相交测试。扫掠只包含平移，不包含旋转。

`sc.overlap` 仍是实体未旋转外框的玩法辅助函数，与本节物理查询用途不同。

`--api` 提供全部 `sc.physics` 函数的参数、范围、默认值、容量与阶段，以及
`ScRayHit`、`ScContact`、关节控制结果和补丁字段；LuaLS 注解由同一数据生成。
`contacts()` 返回上一完成帧的独立副本，不同步身体，可在 draw/ui_update 读取；
其中实体可能已经销毁，使用前仍需验证句柄。
