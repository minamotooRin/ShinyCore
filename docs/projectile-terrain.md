# 批量弹体的地图碰撞

`sc.projectiles.spawn` 的 `terrain=true`（默认值）检测 ASCII 地形和已提交的
Tiled 图块碰撞体。矩形和凸多边形均按弹体圆半径进行连续平移扫掠，包含边和圆角顶点；
起始重叠在 fraction 0 命中。图块翻转和图层偏移沿用内容层生成的碰撞几何。
多边形外框中的空白区域不会被当成墙，不使用导航的保守整格障碍代替真实几何。

地形命中 target 为 0，命中坐标是扫掠时的弹体圆心。普通弹体仅报告最近命中；
穿透弹体报告墙之前的目标并在墙处终止，不命中墙后的实体。相同距离地形优先。
单向平台按一像素厚度阻挡弹体的两个方向，不套用角色下落穿透规则。
`terrain=false` 完全跳过地形检测；普通实体目标仍使用已有 AABB 和阵营掩码规则。

Tiled 地形采用 64 像素空间网格，按世界身份、房间号和 terrain_revision 缓存。
`sc.map` 提交地图修改后，下次有启用地形碰撞的弹体更新会重新构建索引。
不会逐弹扫描整张地图，也不创建弹体刚体。原生直接修改 terrain_shapes 的调用方
必须增加 terrain_revision；弹体池由对应世界拥有，不跨世界重置保留缓存。

专用索引在配置弹体池时预留最多 262144 条格子引用，另有固定 16384 个几何去重标记；
同一个几何跨格子被搜索到时，每弹只做一次精确检测。当前索引约增加 4 MiB 预留存储，
标记为 64 KiB；未创建弹体池的世界不分配这些存储。容量耗尽显式报错，不隐式扩容。
索引构建失败不缓存半成品，修正地图后可重建。重建仍在主线程同步执行。

范围限制：当前只覆盖有限地图已提交的图块碰撞。对象层碰撞导入、流式地图提交、
精确实体形状与图集弹体渲染仍未完成。高速功能测试不代表规定弹幕负载的性能达标。
