# Tiled 导航整合验证（2026-09-24）

有限 Tiled 图块层碰撞现在生成独立的导航障碍掩码，A* 和共享流场共同读取。
导航格与碰撞体有正面积重叠时保守阻挡整格，物理世界仍使用原矩形或凸多边形。
地图提交前完成掩码生成；错误不提交。只有障碍掩码变化才增加导航版本，已有流场
通过版本比较停止输出旧方向，并可继续使用分批 refresh 重建。

原生 `systems` 测试覆盖：格子边界接触、像素偏移、三角形外框中的空白角、翻转后
多边形、一像素单向平台、负坐标裁剪、完全离开地图的碰撞体以及非有限坐标拒绝。
多边形投影按几何预计算，逐格只比较分离轴区间；方向查询不执行全图扫描。

Lua `features` 端到端测试实际导入 Tiled JSON：

- 一列墙阻断 A*；移除中间图块后通路恢复，旧流场自动失效并分批重建。
- 放回墙后再次阻断；重建途中再开门，会丢弃旧拓扑的部分搜索结果。
- 无碰撞图案变化不使流场失效；非法 GID 编辑失败保留图块与有效流场。
- 凸三角形及水平翻转 GID 不误阻挡其外框空白角。
- 图层像素偏移覆盖两个格子时，两格均阻挡，下一格仍可通行。

Windows Release 完整、轻量以及 LLVM-MinGW 22.1.8 ASan/UBSan 构建的相关
`content`、`systems`、`core`、`script`、`contracts`、`features`、`complete_integration`
分别 7/7 通过。新增多边形/偏移导入用例另行复测 features；sanitizer 使用遇错退出设置。
此记录不代替全套测试、图形/音频实机测试或性能门槛验收。

本轮尚未实现身体半径余量、对象层碰撞导航、无限地图及流式块通行边界。
图块修改仍重建全图碰撞及导航掩码，不是局部脏区域修复。
原型地图测试不能代替 2000 单位和大型流式世界性能验收。
接口语义见[地图修改与共享流场](navigation-refresh.md)。

## 对象层静态碰撞（2026-09-27）

显式 `collision=solid/one_way` 对象现已进入共用地形，包含对象层像素偏移、
旋转矩形和凸多边形。变换使用 Tiled 的像素坐标及顺时针角度语义，见
[官方 JSON 对象格式](https://doc.mapeditor.org/en/stable/reference/json-map-format/#object)。
房间单独保留对象几何来源；修改图块重新生成地形时不会遗失静态对象。
这不自动接入游戏工厂创建的动态实体，也不代替流式对象的完整导航契约。

`tests/features.py` 两个新增定向用例在 Windows Release 全功能和无窗口
LLVM-MinGW ASan/UBSan 均通过：

- `test_tiled_object_terrain_survives_tile_edits`：对象层偏移、未声明碰撞的出生区、
  图块开门、旧流场失效/刷新、对象墙保留、真实 Box2D 射线及弹体连续命中。
- `test_tiled_object_geometry_and_diagnostics`：90° 旋转边界、三角形空白角、
  单向平台厚度、自定义导航区域，以及十种错误的地图/层/对象/位置诊断。

已有 `test_tiled_navigation_edit_and_atomic_failure` 同样在两种构建通过。
仅运行相关用例，无图形运行、压力测试或性能结论。API 注解已同步至项目内
SDK `1.0.0-dev.8`，六个带注解项目及未改动的 snapshot SDK 均通过文件哈希审计。
