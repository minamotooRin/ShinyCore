# 寻路与流场验证

## 格子尺寸变化（2026-09-27）

原生 `ScFlowField` 在格网宽高、通行版本不变而 tile_size 变化时也报告 stale，
不沿用旧的身体余量或方向；refresh 用新尺寸重建。Release
`test_systems --navigation` 的窄走廊用例先证实旧尺寸不可达，再改变像素尺寸，
验证过期零方向和刷新后可达；宽高变化也报告 stale。本次只运行该定向入口，
没有性能长测或图形变更。

## 导航脏格提交（2026-09-27）

有限地图编辑及保留格网的流式地形替换先比较旧/新形状，再更新变化形状覆盖的
格子；整张区域替换保持完整计算。ScNavigationUpdate 返回候选掩码与脏格集合，
调用方在两张格网/物理预检成功后提交。Lua 参数和流场句柄语义不变。

Release 定向检查已通过：

- `test_systems --navigation`：多个分离修改、顺序不变性、重叠形状删除、负原点、
  多边形及单向平台连续变更，与完整栅格计算逐格比较；脏区外掩码不变，非法几何
  在浮点排序前拒绝。已有几何/身体余量检查也在该定向入口执行。
- `test_content --navigation`：物理分块局部替换，以及房间/区域/地形版本耗尽时
  保留所有旧数据，修复后提交；没有重跑该文件的字体检查。构建发现缺少 thread
  标准头，已补显式包含。
- Lua 四项：有限 Tiled 编辑原子性、自定义区域同步、流式导航区域和联合地形事务。
  仅导入指定测试方法，未运行所属文件全套。

相同检查已通过完整功能无窗口 LLVM-MinGW ASan/UBSan，设置遇错退出，未报告
内存或未定义行为错误。Release/检测构建均只构建三个相关目标，parallel=2。复现选择器保存于
`build/navigation-dirty-reviewed/run_checks.py`。本次不改变绘制，不重复截图；
没有性能/压力测试。几何收集、排序和候选临时内存仍存在，流场仍完整预算 BFS；
不宣称动态最短路径修复、动态避让或大型世界性能验收完成。

## 身体半径余量（2026-09-27）

A* 与共享流场新增可选世界像素 `radius`，默认 0，范围 0..4096；
从阻挡格与区域边界计算圆形身体的格子中心余量。流场保留半径并在地形失效后重建。
不新增实体存储或逐单位搜索，流场读取仍复用已生成数据；连续运动碰撞仍归物理与控制器。

定向 `test_systems` 和 `tests/navigation_contracts.py` 通过 Windows 完整 Release
及完整功能无窗口 LLVM-MinGW ASan/UBSan（遇错退出）。覆盖恰好容纳身体/过窄门洞、
地图边缘、对角圆形余量、负区域原点、不同半径共享场、分步刷新后开门，以及
非法数值/类型不替换旧场。原生用圆与矩形距离逐格交叉检查通行结果。
现有阶段、预算、过期句柄和批量原子性检查同时通过。

`--api`、LuaLS、参考文档与六个项目注解同步为 SDK `1.0.0-dev.11`；
跨构建生成一致性及七个项目 SDK 审计通过。无绘制变动，没有启动图形窗口、
性能负载或全套回归。动态避让、局部脏块更新与大型世界验收仍待完成。

## 接口与生命周期补充（2026-09-26）

寻路绑定独立至 `src/script/script_navigation.cpp`，与流式地形共用区域准备逻辑。
六个接口均提供字段类型、默认值、范围、阶段及容量；多返回值按名称分别生成
`--api`、LuaLS 注解与参考文档。项目注解副本同步，六个带注解样例的 SDK
版本为 `1.0.0-dev.4`；无注解的 snapshot 未改变版本。

- `tests/navigation_contracts.py`：检查元数据与实际行为、阻挡终点、预算耗尽、
  逐步刷新、槽位替换/区域替换/切房间后的旧句柄拒绝，以及非法转向批次的原子性。
  同时实际执行 draw/ui_update，核对只读与修改阶段。
- `test_systems`：增加阻挡目标及重新开放目标的路径/流场断言。
- `test_script --navigation`：直接将生成号推进至最后一代，确认耗尽后不回绕、
  失败保留有效场、区域重置使旧句柄失效，同一 ScScript 重开 VM 不保留旧区域。
- 仅复查流式测试中的 `test_streamed_navigation_region` 与
  `test_terrain_navigation_transaction`，覆盖负原点、通行更新、坏输入保留、联合提交。

接口、systems 和上述两个流式用例通过 Windows 完整 Release 及完整功能无窗口
LLVM-MinGW ASan/UBSan。生成号极限/VM 复用用例通过 ASan/UBSan；使用遇错退出。
注解同步与生成器声明保留两项检查、七个项目 SDK 审计通过。
没有运行性能负载、全套回归或图形检查；这些变动不改变绘制。
这轮接口检查未覆盖身体半径、局部脏区域更新及大型世界验收。

## 原始流场刷新检查（2026-09-24）

新增 `refresh` 的分批 BFS 与 `sc.tile` 通行性变化的自动失效。
未完成或过期流场不发布方向，不能继续沿旧距离行走。

- 原生测试以每次 7 节点的预算完成流场，与一次完整 BFS 逐格比较方向。
- 验证目标格封闭后失效、返回 unreachable、重新开放后恢复，以及不完整场返回零向量。
- Lua 测试覆盖自动失效、同值写入保持有效、批量 steer 停止单位、非法预算及 draw 阶段拒绝。
- 运行相关 `systems`、`script`、`contracts`、`features`、`complete_integration` 测试，
  API 元数据及各项目注解副本同步更新。

Windows Release 完整构建、轻量构建和 LLVM-MinGW 22.1.8 无窗口 ASan/UBSan
构建均通过上述 5/5 项；sanitizer 使用遇错退出设置，未报告错误。
只记录这些相关测试，不代替全套测试或实机图形验收。

该轮未测 2000 单位性能，当时未实现 Tiled 几何/流式块导航、动态路径局部修复。
