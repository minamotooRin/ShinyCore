# UDP 弱网基础验证 · 2026-09-23

实现 [外部 UDP 代理](../network-testing.md)，加入 CTest `network_faults`。
代理使用 Python 标准库，不增加引擎依赖或发行包内容。

## 实测

Windows 本机回环，一主机三客机四个 ShinyCore 原生进程，另启独立代理进程。
三个客户端各完成 80 条可靠消息的有序发送与确认。配置为 150 ms RTT、
±30 ms 抖动、5% 数据报丢包、3% 重复、seed=734。

| 构建 | 实际执行 | 结果 |
| --- | --- | --- |
| `build/full` GNU Release | `network_faults`、`network_integration` | 2/2 通过 |
| `build-llvm-sanitizers` LLVM-MinGW 22.1.8 | 同上，ASan/UBSan 遇错退出 | 2/2 通过 |
| `build-dev` 网络关闭 | 代理、资源工具、项目工具 | 3/3 通过；代理原生联机子测试明确跳过 |

代理测试文件共 4 项：参数、注入与容量、多客户端真实 UDP 隔离、四进程通信。
独立工具检查也已执行，3 项通过、1 项原生测试按无可执行文件参数跳过。

记录中的 Release 上行收到 469 个数据报，丢弃 23、重复 16；下行收到 483，
丢弃 25、重复 15。ASan/UBSan 运行上行收到 465、丢弃 21、重复 14；下行
收到 473、丢弃 27、重复 15。两次都没有队列溢出或发送错误，结束时队列为空。
数据报包含 ENet 握手、确认和重传，不等于游戏消息数量；不同运行的注入计数
可因调度和重传变化。原始 JSON 位于对应 CTest `Testing/Temporary/LastTest.log`。

## 限制

没有以此宣称四人协作玩法、30 秒重连、20 Hz 快照插值、长期联网或平台验收
完成。测试只验证可靠消息经过外部故障注入后的顺序与交付，并保留原有双进程
协议回归。Linux/macOS 未在本轮运行；未做图形联网截图或公网测试。
