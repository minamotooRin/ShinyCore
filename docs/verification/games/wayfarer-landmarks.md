# Wayfarer 地标与探索导览

新增项目内透明图集 landmarks-v1.png：药师营地、路标、月纹古石、倒木。
素材由 imagegen 生成，原文件保留，来源记入 assets/README.md；运行与打包离线。
scenery.lua 的七处固定装饰按实际图集范围取样，只在当前已加载区域绘制，位于
角色/药草后方。装饰可通行，原地图、对象持久 ID、地形碰撞及存档格式不变。

guide.lua 提供只读任务提示和四区定位图。提示按交谈/采药/清路/交付切换，采药
只从当前加载的实体中选最近者；距离相同时保持输入顺序，附近采空则提示继续
探索。小地图显示固定地标与当前药草，不读取远处块或改动流式加载关注区域。
提示使用当前交互绑定；模态界面、结束和加载等待期间隐藏。
