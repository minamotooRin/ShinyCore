# 命名会话协议状态隔离 · 2026-09-23

`session:state()` 在应用持有的命名会话中保存显式协议数据；与房间共享游戏
状态分离，不进入检查点或自动 trace。接口读取副本，写入整份校验成功后
替换；每会话最多 64 KiB 编码后 JSON、深度 16。容量查询见 session:stats。
语义和重连组合方式见 [重连契约](../../network/rejoining.md)。

## 已执行检查

- 原生 Lua 测试：输入/返回副本隔离、循环/元表/非有限数/根数组/无效 UTF-8
  拒绝、64 KiB 恰好接受与超一字节拒绝，所有失败保留旧值。
- VM 关闭后新绑定可读取旧状态；清除释放数据，同名新会话不继承旧数据，
  旧绑定不能访问新会话。
- 96 个 Lua 分配失败阈值覆盖读取对象的 OOM 路径；既触发失败也有成功路径，
  每次恢复分配后旧协议数据仍完整，检测 C/Lua 跳转边界及原生所有权。
- 实际磁盘存档、加载、两次房间重建：协议数据保持，游戏金币状态正常保存；
  检查保存的 JSON、自动 trace 和最终诊断摘要均不含协议标记。
- 候选初始化可读取，不能写入或清除；draw 可读取，写入被拒绝。
- 真实双进程断开、主机换房、错误令牌拒绝和原玩家恢复已改用 session:state，
  不再将协议记录放入 sc.state。

GNU Release `build/full` 全部 27 项 CTest、网络关闭 `build-dev` 全部 22 项
通过。最终字节边界断言另行重建并运行 net_lua。没有引入运行时依赖、网络
线程或第三方升级；已有数据校验与 Lua 转换逻辑直接复用。
LLVM-MinGW 22.1.8 无窗口 ASan/UBSan 全部 27 项 CTest 通过，包含最终的
字节边界与 Lua OOM 测试，启用遇错退出。

## 限制

这里只提供显式临时数据存储，不自动同步 Lua 局部变量，也不恢复套接字或任意
VM。主动把这些数据写入 sc.state、存档或 watch 仍由游戏负责。正式令牌签发、
四人玩法、弱网重连和长期测试尚待完成。Linux/macOS 本轮未运行。
