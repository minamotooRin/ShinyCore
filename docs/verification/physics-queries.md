# 物理查询验证（2026-09-24）

本轮增加真实矩形/圆/胶囊/凸多边形重叠、平移扫掠，并修正射线同距离命中顺序。
没有完成整个物理工作包：关节电机与限位、分块地形局部重建及通行数据脏区域更新
仍需实现。接口与限制见[物理查询](../physics-queries.md)。

原生 `tests/test_core.cpp` 覆盖圆形外框空白区域、旋转后实际几何、复合形状去重、
传感器与非默认 category/mask、关闭碰撞、地形 ID 0、连续扫掠距离和初始重叠，
以及销毁并复用槽位后的 ID 排序与同距离命中。
实体池满载时同时命中 4096 个实体和地形，检查全部结果及复用同一缓存地址。
这项测试只验证容量正确性，不是 1000 个活动刚体的性能验收。

Lua `tests/features.py` 覆盖上述接口、圆/胶囊/多边形输入、可选矩形旋转、
刚体补丁立即可见、零尺寸、非有限数、凹多边形、额外字段、半径越界和 draw 阶段拒绝。
保留原有射线从地图边界向内发射的回归检查；与扫掠起始重叠契约分别测试。
`core`、`script`、`contracts`、`features` 在 Windows Release 完整构建、轻量构建
和 LLVM-MinGW 22.1.8 无窗口 ASan/UBSan 构建分别 4/4 通过。
Sanitizer 使用遇错退出设置，未报告内存或未定义行为错误。
射线与扫掠在最近命中之后裁剪遍历范围，同时保留相同浮点距离的候选以稳定排序。
本轮只运行这些相关测试，不将其记录为全套测试通过。

复现：

```powershell
cmake --build build/full --parallel 2
ctest --test-dir build/full -R '^(core|script|contracts|features)$' --output-on-failure
```

本轮没有改动渲染路径，没有新增像素或真实输入设备验收。
Linux/macOS、形状查询压力性能、每次查询自定义过滤与旋转扫掠未验收或未实现。
