# Crossing 命名动作与手柄（2026-09-27）

`controls.lua` 集中声明移动、跳跃、交互、救援、菜单和存取档动作；可从独立
设置读取 `crossing` 绑定配置。默认手柄使用方向键或左摇杆、南/西/北侧按钮及 Start。
菜单可进入设置与存取档；连接手柄时，HUD/机关提示显示相应绑定。
`gamepad.jsonl` 随项目分发，可离线重放完整三关。

共享 Shell/Settings 接受可选动作表，菜单关闭帧及持续按住的动作不会穿透玩法。
暂停切换帧跳过控件激活，防止同时按 Start/确认立即点中菜单。标准模块及四个
使用项目同步为 SDK dev.33。内容检查发现并修复宿主遗漏：`--check-all` 的逐房间
运行时现在也借用应用设置服务，初始化可读取持久动作配置，检查模式仍禁止修改。

已执行的必要检查：

- Crossing 集成检查通过：全部房间内容、键盘和手柄三关通关最终状态一致，
  既有渡台/压力板/斜坡、存档/结局/重新开始检查，以及断开/重连后的手柄救援。
- `InputTests.test_shell_gamepad_pause_settings_and_held_action_isolation` 通过，
  覆盖标题确认、暂停开关、按住屏蔽、松开再按、设置返回和切换帧隔离。
- 修改宿主后，Release 构建和 ASan/UBSan 无窗口 `--check-all` 通过。
- 四个变更项目 SDK 哈希审计、Crossing 打包依赖闭包及差异空白检查通过。

实际查看 `build/crossing-controls-reviewed/controller-final.png` 和 `rescue.png`。
前者通过手柄菜单 LOAD 恢复已验证的信号塔存档，仅绘制十帧；后者从标题进入并
救援，仅三帧。原生运行隐藏、不聚焦、静音，存档隔离。首次图发现说明与信号
进度重叠并越界，已将说明移到独立一行，同时下移通知及其目标标记避让区域；
最终两图说明、进度、机关、通知和角色均可见，无相关重叠/截断。清单保存命令、
引擎哈希、输入、快照和检查结论；初版 controller.png 不是最终通过证据。

没有运行性能或长时测试。实体手柄、真实热插拔、人工游玩时长、最终美术音频与
发行验收仍未完成；回放与截图不能代替这些项目。

## 左摇杆补充（2026-09-27）

Crossing 现通过命名动作支持左摇杆水平移动，保留方向键满速移动；走路动画
随输入幅度调速。默认原生死区为 0.2，回放中的 0.6 摇杆输入产生 45/90 的
移动速度。`analog.jsonl` 覆盖半推、归零、反向、断开及重连。短测试确认归零和
断开后速度为零、位置停止变化；`--check-all` 通过。60 帧隐藏、不聚焦、静音
原生截图 `build/crossing-analog-reviewed/analog.png` 已实际查看：角色、目标、
手柄说明和关卡背景可见，新增 STICK 提示未截断。该回放使用模拟手柄输入，
未代替实体手柄及热插拔验收。重绑定设置面板为此前已有功能。
