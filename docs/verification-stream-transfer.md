# 流式对象跨块迁移验证（2026-09-27）

`World.transfer(world, persistent_id)` 要求目标块已发布。它在固定更新边界暂停模拟，
用一次异步分块写入保存原块迁出标记和目标块导入状态，成功后才改变 Lua owner。
根实体、子对象和对象持久 ID 均不重建；目标未加载时返回错误并保留归属。
若缩小关注区域将卸载一个已离开原块的活动对象，`World.request` 拒绝该计划并
释放候选块，要求先加载原块与目标块、迁移对象，再卸载原块。
对象记录格式为 2，旧格式明确拒绝。

定向真实宿主验证：`stream_objects_integration.py` 13 项和
`stream_integration.py` 的对象发布、区域切换、世界协调、跨块往返 4 项通过。
覆盖写盘失败保留两 owner、原块卸载后仍活动、迁回、同一块不能重复归属，以及
新进程从迁入块恢复。Wayfarer `--check-all` 通过；标准模块和项目本地 SDK
均标记 dev.65，项目文件哈希已记录。
Wayfarer 45 帧无窗口日志回放在独立存档目录通过，状态与菜单保存完成。
隐藏、静音的 180 帧原生森林截图已查看：HUD/地图文字清晰、图块和角色可见、
未见裁切。最终文件重拍结果与已查看图片逐字节相同；截图与回放见
`build/wayfarer-transfer-guard-final/`（本地忽略目录）。

目前迁移时机由游戏显式决定；未实现多对象批量迁移、自动逐帧归属扫描、
真实慢盘/进程中断故障、长期负载或跨平台硬件验收。截图只验证该场景的渲染，
不代表完整视觉验收。
