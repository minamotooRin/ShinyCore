# Tiled 对象模板与发行依赖

离线入口为 `python tools/assets.py assets.build.json OUTPUT`。有限/无限正交地图
均可转换为格式 3 的块文件；以下行为属于离线转换，不表示原生有限地图直接读取器
支持全部原始 Tiled 语法。模板在构建时展开，发行游戏无需模板文件或 Python。

## 合并与坐标

对象引用项目内的 JSON 模板或 XML `.tx` 模板。JSON 模板须包含 `type="template"`
与 object；`.tx` 须包含一个 `<object>`，图块对象可先声明一个指向外部图集的
`<tileset firstgid="…" source="…"/>`。实例
覆盖已声明字段，未覆盖字段继承。properties 按 name 合并，同名属性整项覆盖，
未覆盖属性保留，输出按名称排序；属性不是可执行组件，也不自动解释自定义 class。
对象 ID 始终来自地图实例；组/对象层偏移在展开后统一应用一次，对象持久 ID
仍按层路径与地图对象 ID 生成。空属性数组不会删除全部模板默认属性。

file 类型属性按其真正来源解析：继承属性相对模板，覆盖属性相对地图。最终路径
统一为项目相对路径并加入内容哈希依赖；空字符串保留为未设置。已被覆盖的默认
文件不需要存在，也不进入依赖；生效属性指向的缺失/项目外文件会阻止构建。
非法模板、重复属性名和坏 GID 的错误包含源地图、层路径及对象 ID。
当前不接受模板再引用模板；未知自定义属性值作为数据保留，同名值整体替换。
两种对象模板都可引用外部 JSON 或 TSX 图集；格式与限制见 [TSX 导入](tiled-tsx.md)。
XML 模板接受对象名称/类型、位置、尺寸、旋转、可见性、透明度、GID、简单属性及
矩形/椭圆/点/多边形/折线/文字形状；按 Tiled 的 JSON 对象字段归一化。DTD/实体、
嵌套模板、多个对象、内嵌图集、复杂 class 属性和未列出的对象形状明确拒绝。
XML 输入限 4 MiB，诊断包含模板路径与字段；运行时无需 XML 解析器。

## 图块对象

模板继承的 gid 先去除变换标志，再依据模板的 firstgid 求局部图块编号，映射到
地图引用同一个外部图集的 firstgid，最后保留水平/垂直/对角翻转。实例显式写入
的 gid 已属于地图编号，不再映射。无效局部编号、非正交旋转标志和编号溢出报错。

地图尚未包含模板图集时，导入器按首次引用顺序加入它，并分配不与既有图集重叠
的编号范围。图片集合的范围覆盖最大局部编号，不能只使用 tilecount；外部图集、
图像及碰撞元数据继续走相同的导入路径。模板图集须为外部 JSON 或 TSX 图集。

上述继承行为依据 [Tiled 模板说明](https://doc.mapeditor.org/en/stable/manual/using-templates/)，
编号转换依据 [GID 文档](https://doc.mapeditor.org/en/stable/reference/global-tile-ids/)；
字段定义见 [JSON 模板格式](https://doc.mapeditor.org/en/stable/reference/json-map-format/#object-template)。

## 打包与证据

显式发行清单的 stream_maps 依赖展开现在包含：图层/图集图片、图片集合的逐图块
图片，以及块对象最终生效的 file 属性。源模板/源地图不因引用关系而进入运行包。
模板修补时构建器提升至版本 8，XML 模板接入时为版本 12；当前版本 13 见 tools/assets.py，
原生块格式仍为 3。

2026-09-27 的必要检查通过：三项模板用例覆盖属性覆盖/保留、来源路径、依赖变更
使缓存失效、重建一致、已有/模板独有图集、翻转位、稀疏图片集合编号以及错误诊断。
既有负块坐标与对象归属两项检查通过；两项打包用例验证新增文件依赖和越界拒绝。

`build/tiled-templates-reviewed/` 保留一个转换后只按发行闭包复制的项目：不包含

覆盖值、文件路径和重映射 GID 正确。manifest 保存命令、引擎哈希与实际文件清单。
