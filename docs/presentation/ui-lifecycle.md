# 独立 UI 更新

场景可提供 `ui_update(dt)`，使用普通 Lua 局部状态维护界面，再由 `draw` 提交
绘制。它在玩法 update 之前执行，加载等待和调试暂停期间仍可执行，不创建
额外世界。没有声明该回调的场景保持原行为。

```lua
local UI = require('shiny.ui') -- 标准模块必须在加载/初始化阶段载入
local Input = require('shiny.input')
-- 在 init 创建 ui；在 ui_update 调用 UI.update(ui)，在 draw 调用 UI.draw(ui)。
-- ui_update 内先 Input.update(actions, 'ui')，再把 actions 传给 UI.update。
-- update 内先 Input.update(actions)，再查询玩法动作。两个回调共用同一动作对象。
```

- 实时图形输入每个显示帧处理一次，在本帧任何模拟更新之前；dt 是宿主帧时长，
  限制为 0..0.25 秒。有界实时图形运行计划推进时传入 1/60，否则为 0。
  无窗口及输入回放在每个固定输入快照交给玩法前传入 1/60；加载/调试等待时为 0。
  回放的 UI 更新按固定帧进行，与实际机器显示频率无关。
- `sc.input.*` 在回调内读取该次宿主输入快照；返回后恢复模拟快照，即使回调
  失败也恢复。回放不采样真实设备；等待期间清除重复的按放、滚轮及提交文本。
- 回调可以改变自己的 Lua 界面状态、设置文字焦点、读写剪贴板、显式暂停/恢复
  模拟或退出。实体、物理、资源、存档、共享状态、玩法随机数及网络变更禁止执行。
  游戏操作应作为明确的 Lua 请求在下一次 `update` 中处理。
- 绘制仍只允许在 `draw` 中进行。首次加载模块不允许放在 UI 回调，指令数与
  Lua 内存限制继续生效。宿主时间及 UI 更新次数不应参与玩法随机或存档规则。
- 标准 UI 仍由游戏显式调用，同一棵树不要在两个回调重复更新。
  `shiny.input` 的 ui/game 两路历史隔离，UI 消费会传给后续固定更新，包含显示帧
  间的短按和同显示帧内的多次补帧。关闭菜单后，被消费动作保持屏蔽直至松开，
  对应释放也不穿透；新一次按下正常恢复。详见[命名动作](../runtime/input-actions.md)。
- UI 设置的文字焦点保留到绘制/设备处理；玩法更新不会自动清除它。
  在 UI 中退出会跳过尚未开始的玩法更新；暂停/恢复立即作用于随后物理步。
  块读取失败可通过 `sc.stream.failure/retry` 展示并重试，见[流式恢复](../content/streaming.md)；
  索引/候选房间等其他加载失败仍需各自的恢复流程。

输入桥接已使用短回放、无窗口 sanitizer 和隐藏原生输出检查；真实暂停按键、
IME 与剪贴板设备行为仍需实机验收，不能用脚本测试替代。

### 局部布局更新

`UI.set` 先验证整份补丁，再提交并标记依赖。文字、颜色、选择值、提示和回调变化
不重算控件矩形；文字布局仍按内容、宽度、字体和组合状态缓存。相同尺寸值不使
几何失效。尺寸、锚点、间距、布局种类和显隐变化标记节点至根的路径，流式排列
重新分配受影响的兄弟控件；收到相同分配矩形的干净子树直接复用。

列表 items/row_height 变化更新内容高度和滚动上限；滚动只更新所属路径与移动的
子树。显隐和页签切换更新可见顺序，保持绘制、命中、焦点的共同顺序。窗口逻辑
尺寸变化仍复用分配矩形不变的固定面板。draw 不执行布局或修改失效标记。

动态字段通过 `UI.set` 修改，结构变更仍重建树。直接改动主题布局字段后可设置
`ui.dirty=true` 请求完整重排；它也可用于调试比较增量结果。`UI.inspect` 和原生
检查面板在几何更新待处理时标记 layout_pending，避免报告旧矩形为当前结果。
更新仍遍历可见控件检查文字缓存和交互，不宣称所有 UI 工作都只访问脏节点。
实现与必要验证见[局部布局记录](../verification/systems/ui-layout.md)。

### 锚点与面板样式

anchor 默认为 `top_left`，支持 `top`、`top_right`、`left`、`center`、`right`、
`bottom_left`、`bottom`、`bottom_right`。它在父布局分配的矩形内对齐已限幅的
控件尺寸，再加 x/y 偏移。overlay 的子控件可使用整个内边距区域，row 的子控件
可使用整行高度；普通列/网格仍遵守原有行尺寸分配。窗口逻辑尺寸变化后重算。
布局尺寸、间距必须有限且非负，x/y 可为负，min 不能大于 max；UI.set 预检失败
不改变节点或脏标记。center 同时对齐两个轴，包含显式高度的 overlay 子控件。

```lua
local theme={}; for key,value in pairs(UI.theme) do theme[key]=value end
theme.skins={button={resource="panel",slice={left=4,right=4,top=4,bottom=4}}}
local ui=UI.new({id="hud",kind="overlay",padding=8,children={
    {id="menu",kind="button",anchor="bottom_right",w=100,h=32,text="Menu"},
}},theme)
```

skin 是普通图片描述表：resource 必填，可含 slice、source_x/y/w/h、color、
flip_x/y、diagonal。绘制固定使用屏幕坐标和原有 UI 顺序，不接受 layer/material。
节点 skin 优先于 `theme.skins[kind]`；false 禁用该节点的图片背景，使用普通颜色
背景。不指定任何图片样式的默认主题仍无额外资源依赖。图片区域和九宫格契约见
[图片绘制](image-regions.md)。流式皮肤必须在首次绘制前纳入房间图片集合。

UI.new/UI.set 复制样式绘制字段及 slice；随后直接修改原样式表不会改变已准备的
绘制参数。通过 UI.set 重新应用样式，并在 draw 前完成 layout/update。skin 的
结构/数值先验证；资源名、PNG 边界和驻留情况仍由原生绘制校验。焦点条保留，
有皮肤的分组页签以底部 accent 条显示选中状态，不覆盖整张皮肤。

`examples/ui_panels` 提供项目内标准库、原创 16×16 边框图片和九点锚定示例。

### 文字控件拖选

输入框按下左键时设置选择起点；按住拖动和最后释放都会更新终点，移出控件
仍保持捕获。Shift 点击保留原起点。光标只落在字素边界，不拆分中文 UTF-8
字节或组合字符；单行和多行均适用。多行按实际行高定位，不把一行下半部
误判为下一行。控件隐藏、禁用或被模态窗口排除时取消捕获，恢复可见不会
继续旧拖动。移动选区不增加撤销记录，替换选区仍可一次撤销。

越界拖动将指针定位限制在输入框实际可见边缘；长文本按 UI 的 `dt` 有界自动
滚动，多行沿纵轴、单行沿横轴，指针远离窗口也不会一帧跳到文末。释放帧更新
当前边缘的选区终点；释放与 `dt=0` 不增加按时间推进的越界滚动，正常的光标
可见性调整仍会发生。
父级裁剪区域同样限制可见边缘。定向回放与隐藏原生截图见
[拖选验证](../verification/systems/ui-text-drag.md)。
光标仍在输入框可见区内时保留当前滚动位置；只有越出边缘才移动视口，避免普通
方向键编辑时把光标反复吸到右下角。

### 文字光标与选区

已有选区时，单独左/右键分别收起到选区起点/终点，不再额外移动一个字素；
Shift+方向键继续以字素扩选。多行上下移动保留目标水平位置，经过较短行后
仍能回到原列；Page Up/Down 按输入框可见完整行数移动，最少一行，可配合 Shift。
垂直移动使用实际排版行，支持自动换行；越过首尾时停在最接近目标列的边界行。
鼠标定位、水平移动、文字修改、焦点/排版变化和输入法组合会重置目标列。

Home/End 到换行符定义的当前行首/尾，Ctrl+Home/End 到全文首/尾，均支持 Shift。
Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；光标操作不产生撤销记录。
所有这些编辑按键在输入法组合及结束帧仍交给输入法。显示滚动保持光标可见。
直接使用 `shiny.textedit` 时，`home(editor, selecting?, document?)` 与
`finish(editor, selecting?, document?)` 的第三参数为 true 才选择全文边界。

### 输入法组合文本

组合文本仅作为选区替换预览参与排版，不改变 `value`、撤销栈或触发 `on_change`。
预览使用主题 accent 颜色和下划线，后续正文随之移动；多行换行、单行水平滚动
与候选框定位使用同一布局。长文本按字素拆成原生绘制命令，绘制阶段不重新排版。
组合光标现使用输入快照的 cursor；不再固定在组合文本末尾。目标片段使用 selection
背景，保留 accent 字色和下划线。UTF-8 位置经换行清理换算后对齐到字素边界；
只改变光标、目标范围或分句属性也会更新缓存。没有原生位置数据时保留末尾光标及空目标范围。
分句元数据可用时，未转换片段使用点状下划线，已转换片段使用正文色和细下划线；
两种目标状态使用选区背景与粗下划线，错误片段使用 `theme.error`（默认 `#F47C7CFF`），
固定片段使用 muted 色且无下划线。同一字素内属性冲突按目标、错误、已转换优先，
避免拆开组合字符。分句边缘保留间隙；无分句元数据时沿用首个目标范围。
相关接口及[新增分句截图证据](../verification/systems/ime-segments.md)见[输入契约](../input.md)。

观察到组合文本时，方向、退格、删除、撤销、Tab 等按键交给输入法；结束组合的
提交/取消帧也不再次执行编辑动作。提交替换选区并形成一次可撤销修改；取消保持
正文和选区。Enter 与提交文本同帧时只插入文本，单独 Enter 才给多行框换行。
提交、组合预览和粘贴统一 CRLF/CR 为 LF；单行框移除换行。

同树中焦点离开后清除预览，尚未结束的组合会话不能把提交内容转移到其他输入框。
这属于 UI 数据隔离，不是原生输入法取消命令。快照提供组合光标、首个目标范围及
有界的分句/转换属性。Windows 输入法窗口、
不同候选编辑方式和 DPI 下的实际位置仍未实机验收。

### 方向焦点导航

已有焦点时，键盘方向键按控件位置移动；手柄十字键还可从无焦点状态进入菜单。
优先选择同一行或列投影重叠的控件，再按中心距离选择，完全相同时保持声明顺序。
隐藏、禁用及当前模态外的控件不参与。边缘保留当前焦点；Tab／Shift+Tab 和
右／左肩键继续按声明顺序循环。无焦点时键盘方向键保留给玩法，Tab 可进入菜单。
导航使焦点滚入可见区，同一快照若有两个有效方向，优先处理水平方向。

### 长按重复

键盘方向键、Page Up/Down、Backspace/Delete 和手柄十字键首次按下立即处理；
持续按住 0.4 秒后，每隔至少 0.05 秒再处理一次。文字编辑、列表、滑条、页签
和空间焦点导航共用此规则。Enter、Space、Tab、肩键及剪贴板/撤销快捷键仍只
响应真实按下边沿，长按确认不会连续激活按钮。

计时归 UI 树所有，由 UI.update 的有限非负 dt 推进，draw 不推进。
每次更新最多为每个来源生成一次重复，慢帧不会补发一串回调，dt=0 不重复。
鼠标按下、Tab/肩键切换、外部焦点改变及模态层变化重置等待时间；空间方向
导航可连续跨控件移动。松开/设备释放清除对应计时，输入法组合及其结束帧
抑制重复编辑，结束后重新等待。原生输入快照与玩法按下边沿不被修改。

控件内部操作优先：滑条和分组页签使用左右，列表使用上下，输入框使用键盘
方向键编辑文字。其余方向可离开控件；手柄在输入框上移动焦点，文字由键盘或
输入法编辑。组合文本期间不切换焦点。导航进入另一个控件时，同一次方向输入
不会再改变新控件的数值、选中项或文字光标。传入 actions 时，已使用的方向来源
被消费，下层游戏动作不会同时触发。

### 确认控件与滑条

按钮、复选框、页签使用 Enter、Space 或手柄 South 确认；列表对已选项使用相同
按键触发 on_activate。均按按下边沿处理，按住确认键不会连续点击。输入框中的
Space 仍是普通提交文本，不激活其他控件。复选框 value 为布尔值，默认 false。

滑条 value 为 0..1，默认 0；step 默认 0.05，page_step 默认 min(1, step×10)，
两种步长均须大于 0 且不超过 1。UI.new 和 UI.set 验证字段类型/范围，非法补丁
不修改节点。初始默认值不会触发 on_change。

- 键盘左右或手柄左右按 step 调整；PageUp/PageDown 增减 page_step。
- Home/End 直接到 0/1；相反方向同帧按下相互抵消。触及端点时不重复发 change。
- 鼠标沿控件宽度连续调整，不按 step 量化；移出仍捕获，释放使用最终位置。
  同帧按放也有效；零宽度不执行鼠标换算，隐藏/禁用会取消捕获。
- 值实际变化才触发 on_change(value)，绘制提供轨道、填充和滑块。其他数值范围
  由游戏将规范化值映射，例如 size=14+value×12。

提供 actions 参数时，这些确认/调整键在本轮被消费，包括确认回调清空焦点的
情况。原始 sc.input 快照不修改；消费契约见[命名动作](../runtime/input-actions.md)。

### 滚动容器与焦点

`kind='scroll'` 默认纵向滚动；`axis='horizontal'` 将直接子节点沿 X 轴排列，
按其宽度滚动和裁剪。范围由可见直接子节点的实际矩形及 padding
计算，与当前滚动位置无关；隐藏内容、改变尺寸后自动收回越界偏移。布局采用
控件 min/max 尺寸后的实际高度，网格每行按该行最高控件推进，避免行间重叠。

```lua
UI.layout(ui, width, height)
local actual = UI.scroll_to(ui, 'inventory', 240) -- 当前轴的像素偏移，自动限制到有效范围
```

`scroll_to` 接受滚动容器或列表 ID，要求已有布局和有限数值；在 update/回调中
调用，返回实际偏移并完成布局。结构或尺寸变更仍通过 UI.set；draw 只提交绘制。
Tab、手柄导航及程序改变 `ui.focus` 后，控件会逐层滚入祖先滚动容器；调整布局
或窗口尺寸也会检查当前焦点。回调中显式 scroll_to 优先于自动显露，不强制跳回。

鼠标滚轮先交给最内层可用容器，到边界后沿父链传递，不转交旁边的容器或越过
模态层。横向容器优先使用横向滚轮，没有横向输入时接受纵向滚轮；列表仍只纵向。
滚动容器和列表显示对应轴的滚动条；点击轨道按视口长度翻页，拖动滑块时
保持捕获，移出视口仍可拖动/释放。释放不会点击下方内容。隐藏、禁用或模态层
改变会取消捕获。惯性滚动尚未提供。

UI.inspect 提供 scroll_axis、scroll_max 和 scroll_capture，分别表示轴向、当前轴的
偏移上限和滑块捕获。
UI.update 的 pointer 返回值也包含滚动条与滚轮接收状态。

### 提示文本

任意可见、启用的节点可声明 `tooltip='说明'`；false 或空字符串关闭提示。
`tooltip_delay` 默认 0.5 秒、`tooltip_width` 默认最大 240 像素，可在节点或主题
中覆盖。delay 须有限且非负，width 须有限且至少 24，文本上限 4096 字节。
UI.set 在修改前验证这些字段；动态更新仍使用 UI.set。

提示采用最近的鼠标悬停或键盘/手柄焦点来源，程序改变焦点也可显示提示。
覆盖在上方但没有提示的控件不会让下方提示穿透。目标隐藏、禁用、离开裁剪区
或模态层时清除；点击、拖动、滚轮及文字输入重置等待时间。已显示提示可用
Escape 关闭，离开目标或切换输入来源后才重新等待；通过传给 UI.update 的动作
表消费这次 Escape，不关闭所属控件或弹窗。

提示沿用主题字体大小和所属节点/主题字体，按字素换行，出现在鼠标或控件旁。
靠近屏幕下缘时向上放置，并限制在逻辑视口内；超高文本最后一行显示 `...`。
它在 UI 树和所有祖先裁剪结束后绘制，无焦点、命中区或点击回调，不改变原树布局。
计时和排版只在 update 中执行。详细长说明应使用可滚动的弹窗。

提示归所属节点的稳定 ID 标识；UI.inspect 为该节点返回 tooltip_visible，
显示时另有 tooltip_rect 和 tooltip_truncated。原生 JSON Lines `ui` 检查也提供这些
字段，以及 scroll_max/scroll_capture；面板显示提示和拖动标记，完整矩形由协议读取。

### 列表控件

`kind='list'` 使用稠密 `items` 数组；元素可以是字符串或带 `label` 的表。
`row_height` 默认 24，必须是有限正数。`value` 是从 1 开始的选中索引，nil
表示未选中。选择改变触发 `on_change(index)`；数据缩短导致索引失效时清空
选择并传入 nil。Enter、Space 或手柄 South 触发 `on_activate(index)`，鼠标点击只选择。

方向键/手柄上下逐项选择，PageUp/PageDown 按可见行数翻页，Home/End 到首尾。
选中项自动滚入可见区。Tab/左右 Shift+Tab 或手柄肩键在控件间切换焦点；
手柄进入列表的方向键不会同时移动选中项。点击列表空白区域不激活旧选择。
绘制仅遍历可见行，选中背景使用主题 `selection` 颜色。初次绘制前仍需在
`init` 调用 `UI.layout`，布局和交互不放在 `draw` 内执行。

一万条数据的无窗口回放以 32 条绘制命令预算检查虚拟绘制、导航、选中项滚动、
清空及替换数据。它不是规定的 500 控件性能验收。

需要筛选/排序的列表应为每一行提供稳定字符串 `id`，例如：

```lua
UI.set(ui, 'items', {items={
    {id='trail-boots', label='行旅靴'},
    {id='moon-grass', label='月光草'},
}})
UI.set(ui, 'items', {value=false}) -- 显式清空选择
```

同一数据数组要么每行都有 ID，要么全部不带。ID 为 1..128 字节、不含 NUL 的
唯一字符串；label 为最多 4095 字节、不含 NUL 的字符串，省略时显示行号。
items 与记录必须是普通无元表数据，数组不能有空洞或附加键。UI.new/UI.set
在改变节点前预检数据及 row_height/value，失败保留旧列表和布局。

通过 UI.set 替换 items 时，原选中行有 ID 则按 ID 找到新索引；该 ID 被移除
或新数组不再使用 ID 时清空选择，不误选占据旧索引的物品。不带 ID 的列表仍
使用索引。显式同时传入 value 优先于 ID 保留；value=false 表示清空。
items 的过滤/排序及带 ID 记录的变更应通过 UI.set 提交，不原地修改列表字段。
value 和 on_activate/on_change 参数仍是索引，游戏可用 items[index].id 取稳定引用。

数据替换造成索引变化或清空时，下一次 UI.update 发出 on_change；显式设置
value 沿用其他控件的规则，不主动触发 change。多次提交在更新前合并为最终值
的一次通知。变更后的选中行滚入可见区，焦点仍属于列表控件。
UI.inspect 和原生 JSON Lines `ui` 检查均提供 selected_item_id，不触发元方法。

### 页签与面板

页签使用 `kind='tab'`、`group='组名'`、`page='面板 ID'`。同组默认选择首个
可用页签，也可用 `value=true` 指定唯一初始选择。一个面板只能归属一个页签，
且不能包含同组的任何页签；缺失面板或重复初始选择会在 `UI.new` 报错。

```lua
local ui = UI.new {id='root', children={
    {id='tabs',kind='row',h=32,children={
        {id='gear',kind='tab',group='inventory',page='gear_page',text='装备'},
        {id='quests',kind='tab',group='inventory',page='quest_page',text='任务'},
    }},
    {id='gear_page',children={{id='gear_title',kind='label',text='装备列表'}}},
    {id='quest_page',children={{id='quest_title',kind='label',text='任务列表'}}},
}}
```

点击或确认选择页签；键盘/手柄左右在同组可用页签间循环并选中。切换自动
更新 `value` 和面板可见性，`on_change(page_id)` 仅在选择变化时触发。
程序调用 `UI.select_tab(ui,'quests')`，不能通过 `UI.set` 单独修改分组页签的
value/group/page/kind；关联变化应重建树。程序修改后在绘制前运行 UI.layout
或 UI.update。交互回调中的布局变更会在同次 UI.update 返回前完成，不在 draw
中补算。面板的 Lua 状态保留，不因切换重新创建。

### 模态焦点恢复

同一 UI 树中，布局顺序最后一个可见 `modal=true` 节点接收交互。打开弹窗
时保存原焦点，将焦点移入弹窗的首个可用控件；若原焦点已在弹窗内则保留。
关闭后恢复原控件，已隐藏或禁用的恢复目标不会重新获得焦点。嵌套弹窗逐层
恢复；关闭后台弹窗不会重置仍在前台的控件焦点。

弹窗变化会在更新结束前重新检查焦点，打开弹窗的确认输入不会再次激活新
弹窗控件，关闭它的输入也不会继续激活下层控件。变化涉及当前模态层时取消
旧鼠标捕获。空弹窗仍阻止同树下层交互，但没有可聚焦控件。不绑定隐式 Escape
关闭行为；游戏通过按钮回调中的 `UI.set(ui,id,{visible=false})` 明确关闭。

### Agent 检查数据

`local nodes, next_offset, total = UI.inspect(ui, offset?, limit?)` 返回作者声明顺序
的平面树，包含隐藏节点与父 ID。offset 从 0 开始，默认 0；limit 默认 128，
范围 1..256；next_offset 为 nil 时完成。它不触发布局计算。

记录包含可见/启用状态、焦点、捕获、模态标记、标量 value、页签关联、列表
条数与滚动位置、输入框光标及选择起点。禁用状态沿父链继承，交互同样遵守。
隐藏节点或布局待更新时不返回旧矩形。文本 value 超过 256 字节时返回不拆分
UTF-8 字符的预览，并附 value_truncated/value_bytes。不展开函数或任意对象。
返回数据均为独立值；读取节点字段不调用其索引/长度元方法，异常父链有界报告。

例如在固定更新中将一页及 next_offset/total 放入 `sc.debug.watch`，供自动测试
读取。分页适用于完整树；不能把默认第一页当作全部控件。

devtools 构建的 `UI.new` 还会按根 ID 自动注册弱引用，供 JSON Lines `ui` 命令
和原生面板直接读取；同名新树替换旧绑定。它不逐帧复制数据，也不调用本 Lua
检查函数，因此可在源码断点处读取。注销、容量及分页契约见[调试协议](../runtime/debug-stdio.md)。
