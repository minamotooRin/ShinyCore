# 地图修改与共享流场

`path(sx,sy,gx,gy,budget?,radius?)` 接受零起点的格子坐标，返回一张包含
`status, visited, points` 的表。成功路径包含起点和终点；不可达或预算耗尽
返回空 points。合法但被阻挡的起点/终点返回 `unreachable`、零访问数，
越界坐标则报错。`flow(gx,gy,budget?,slot?,radius?)` 同样使用格子坐标，返回
三个独立值 `handle, status, visited`；默认预算 16384，默认槽位 1。
`direction(handle,x,y)` 接受世界像素坐标，返回 `dx, dy, status`。
流场整体 `ok` 不表示任意格子均可到达目标；目标格、区域外和不连通格子
仍返回零方向。寻路结果是独立快照，不会随地图修改而自动更新。

`mask(radius?)` 按当前选中的格网返回只读快照：`x/y` 是世界像素原点，
`cell_size` 是格子像素尺寸，`width/height` 是格数，`rows` 用 `.` 表示可通行、
`#` 表示阻挡。`radius` 与 path/flow 共用同一套圆形身体余量计算；
地图或地形变动后需重新调用。它不改变流场，可在 draw/ui_update 读取。
最多返回 16384 格，仅显式调用时生成；适合离线连通摘要工具读取真实通行语义，
不宜在每个单位每帧调用。当前接口本身不提供跨未加载块的全局寻路。

`radius` 为世界像素半径，范围 0..4096，默认 0。非零时按圆形身体检查格子中心
距阻挡格和区域边界的余量，刚好接触允许通过。窄于身体直径的通道不可达；
对角距离使用圆与矩形距离，不用方形膨胀误封可通过的角落。
底层被几何覆盖的格子仍整格阻挡，因此它是保守的格网路径，不是精确几何导航网格。
流场保存半径，refresh 重建时继续使用；同尺寸角色共享一个场，不同尺寸可使用不同槽位。
例如 `path(2,3,6,3,nil,6)` 与 `flow(6,3,nil,2,6)`，可用 nil 保留中间默认值。
半径由游戏显式选择，不读取实体形状；包围圆可保守覆盖矩形或其他身体。
路径余量针对格子中心及相邻中心连线。direction/steer 仍是速度建议，任意偏离中心的
位置、过大单步位移与移动实体避让由游戏控制器和物理碰撞处理，不承诺连续运动无碰撞。

房间最多保存 16 个共享流场。句柄含房间代号、生成号和槽位，保持在 52 位
整数范围内，不用于存档。每次成功调用 flow 替换槽位都会使旧句柄失效；
失败预检保留旧场。refresh 保留句柄。生成号耗尽时拒绝替换，不回绕复用。
`region(x,y,rows,cell_size?)` 原子替换局部导航格网；原点为世界像素，
默认每格 8 像素。rows 为等宽的 `.`/`#` 行，总计最多 16384 格。
无参数 `region()` 恢复房间格网；两种成功替换均使已有流场句柄失效。
局部格网的路径坐标不含原点偏移，direction 则包含该偏移。

当前导航以 `ScMap` 格子为通行数据：`.` 且未被 Tiled 碰撞覆盖的格子可通行，
`#` 和 `=` 不可通行。导航掩码与真实物理几何分开，不把斜坡替换成方块。
`sc.tile` 或 `sc.map` 改变通行性时，通过地图版本使已有流场失效为 `stale`；重复写入相同值，
或在 `#` 与 `=` 之间切换，不触发重建。
不再允许过期距离场继续引导单位。`direction` 对过期、未完成或不可用流场返回
零向量，第三个返回值是流场状态；`steer` 此时将批量实体速度置零。

```lua
local field, status = sc.navigation.flow(12, 8, 128)
-- 在 update 中，每个共享流场每帧只维护一次；不要每个 NPC 都调用。
status = sc.navigation.refresh(field, 128)
sc.navigation.steer(field, enemies, 40) -- 未完成时写入零速度
```

`refresh(field, budget)` 保持目标和句柄，最多再扩展 `budget` 个 BFS 节点，
返回 `status, visited`。预算为 1..1048576，visited 是本次构建累计访问节点数。
过期场第一次 refresh 清空旧距离并重启，之后继续未完成队列；只有整个场构建完成
才发布方向。状态为 `budget_exhausted` 时可以下一帧继续，而不是从头重复同样的搜索。
已完成场无需重复搜索；目标格被封闭时为 `unreachable`，重新打开后可再次构建。
房间内地图尺寸必须保持一致；切房间后需要新的流场句柄。

region、flow、refresh、steer 只能在 load/init/update 调用；path、mask 和 direction
也允许 draw/ui_update。steer 接受无元表、无重复、无失效句柄的稠密实体数组，
空数组合法。整个批次预检后才更新各实体中心对应的速度，返回实体数量。
数值参数不接受可转换的字符串；有限值、整数、范围和参数数量均显式校验。

结果与一次足够预算的 BFS 使用同样的固定邻居顺序。方向读取不执行地图全量扫描，
同一场可供大量单位共享。原生调用方直接修改 `ScMap` 后应调用 `invalidate()`；
Lua 的 `sc.tile` 和 `sc.map` 自动处理。原生读取当前状态使用 `field.state(map)`，
公开 status 表示最后一次构建状态。重建复用已分配的距离和队列存储。
原生调用方在每格像素尺寸变化时，旧场也会变为 stale；refresh 按新尺寸重算
身体余量。宽高变化同样报告 stale，但需重新 build，不能 refresh。
Lua 成功替换 region 仍直接使旧句柄失效。
第一次重启仍有一次全场距离清空及身体余量计算，因此节点预算不是严格 CPU 毫秒上限。

这是格子修改的失效与分批重建机制，不是动态最短路径的局部修复算法。
当前有限 Tiled 图块层的矩形、凸多边形、翻转及像素偏移已接入：与碰撞体有正面积
重叠的整格保守标记阻挡，仅边界接触不阻挡邻格。单向平台按其一像素厚度生成障碍；
俯视方格导航不尝试跳跃或下落穿透。凸多边形使用分离轴测试，不把外框空白角也算阻挡。
图块编辑只有在合并后的障碍掩码变化时更新版本；失败编辑保留原通行数据。
启用 `navigation.region` 后，`sc.map` 同时更新房间格网和该区域的地形障碍掩码，
按各自原点及格子尺寸计算；区域 rows 中显式写入的 `#` 保持不变。
每张格网独立比较通行掩码，区域外修改不使局部流场失效。修改没有替换区域，
因此已有句柄保留，并在需要时变为 stale。两套掩码及地形全部预检后一起提交；
任一版本耗尽或几何错误均保留旧图块、地形、掩码及流场。
原生内容调用方持有额外格网时传入 `sc_project_tiles(world, region)`；省略时仅
更新房间格网。自定义 rows 自身仍由游戏提供，不随房间 ASCII 格子自动重写。

流式地图可通过 `sc.stream.terrain(shapes, navigation)` 同时提交碰撞几何与
局部导航格网，准备失败保留旧地形和旧场；未加载区域由上层模块生成阻挡格。
地形改变而格网未替换时，通行掩码变化使场变为 stale。见
[流式图块](../content/stream-tiles.md)及[世界协调](../content/stream-world.md)。
有限 Tiled 对象层也可显式声明静态碰撞：对象的字符串自定义属性
`collision="solid"` 或 `"one_way"` 同时生成物理地形与导航障碍。
默认 `empty`，NPC、出生点等普通对象仍只提供给 Lua 工厂。
solid 支持矩形与 3..8 点凸多边形，接受绕对象原点的旋转及对象层像素偏移；
one_way 仅接受未旋转矩形，导航仍按一像素厚度阻挡。编辑可见性不禁用碰撞。
凹多边形须先离线分解成凸对象；显式碰撞中的椭圆、图块对象、点、折线和文字
当前拒绝，并报告地图、层、对象 ID 和源位置。坐标及变换后顶点限 ±1000000，
几何外框各边为 0.16..4096 像素；与图块共享 16384 个地形形状上限。
`sc.objects()` 保留这些记录，x/y 已加层偏移；游戏工厂不应重复生成其刚体。
这些形状归当前房间静态地形所有，图块编辑不会移除；移动门等可变对象继续使用
Lua 实体。此支持不自动把任意动态实体加入导航。

身体余量已覆盖静态格网。有限地图 sc.map 编辑、流式地形替换及保持原点/尺寸的
局部导航区域已按几何变化更新脏格：比较旧、新形状的有序多重集，标记增删形状
实际覆盖的格子，仅重新计算这些格子的全部形状贡献。重叠形状删除一份时不会
错误开放另一份仍阻挡的格子；多个远离修改不包含中间未变形状，输入顺序变化
本身不触发更新。合并矩形被拆开时允许保守包含其旧覆盖区。

初始化/区域替换仍完整计算。原生 sc_navigation_patch 返回候选 blocked 和 dirty，
不会修改地图；调用方须保证旧掩码对应 before，且格网尺寸、格子大小和原点不变。
sc_project_tiles(world,region,true) 用于满足这些前提的原生局部编辑；默认完整计算。
两个导航掩码和物理地形继续先预检再提交，实际掩码未变不增加版本。

此实现仍收集/比较已加载几何，并保留候选临时数组；没有建立动态空间索引。
流场仍按预算重建完整 BFS，动态单位避让也未实现；不把脏格掩码更新称为
动态最短路径修复或大型世界性能验收。
A* 每次直接读取当前格子，不缓存旧路径；Lua 已保存
的路径不会自动改写，需要按玩法规则重新查询。
失效本身不遍历或停止世界中的实体；游戏仍须在每帧调用 steer，或显式处理零方向，
否则实体之前设置的速度会继续生效。
