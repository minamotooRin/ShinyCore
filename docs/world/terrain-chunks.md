# 分块地形物理所有权

物理后端按 32×32 图块拥有静态身体。ASCII 连续水平地形在块边界拆分；
Tiled 碰撞形状按左上角所属块归属，跨块多边形保留完整几何，不重复创建。
Tiled 相邻矩形只在同一世界坐标块内合并，包含图层偏移；不能先跨块合并
再把整条地形归入首块，否则修改邻块会破坏局部替换语义。
负坐标使用向下取整。房间外围边界有独立身体，局部地形修改不重建它。

地图发生变化后先生成候选几何，逐块比较，未变化的块保留原生身体及接触。
变更块先创建候选身体，全部成功后才替换；中间不推进物理，失败时释放候选，
保留原有地形。单向平台继续使用独立、地址稳定的形状标签。
空块不保留身体；房间销毁先释放块身体，再释放物理世界。

原生 `sc_physics_terrain_stats` 提供块数与累计替换数，不触发同步。
这是生命周期诊断，不是 Lua 游戏规则接口。当前仍扫描已加载地图来识别变化。
流式块的绘制/物理/对象联合提交、加载边界与重访恢复见 [世界协调](../content/stream-world.md)。
有限 Tiled 显式静态对象与图块使用同一分块物理路径，图块编辑保留对象几何。
导航掩码现在按增删几何的覆盖格局部更新，保留未变格和重叠形状贡献；
形状收集与物理块比较仍扫描已加载地形，详见[导航更新](navigation-refresh.md)。

## 验证（2026-09-25）

原生测试覆盖单块编辑、射线碰撞更新、相邻块保留、空块删除、负坐标归属、
房间边界独立调整、重复同步不重建，以及一个候选已准备后另一个候选失败的
整体回退。失败后修正数据可继续提交，不残留临时身体。

Windows 完整构建及无窗口 ASan/UBSan 各通过 core、systems、script、features、
complete_integration、stream、stream_integration 七项；轻量构建通过前五项。
所有运行均为无窗口验证，未执行原生图形或性能验收。

Tiled 内容回归额外验证 0、-8、-256 像素图层偏移下的块边界、单格删除只
替换一个物理块及删除后的射线结果；ASan/UBSan 的 content、core、features、
complete_integration、stream_integration 五项通过。
