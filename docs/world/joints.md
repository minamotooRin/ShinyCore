# 关节控制

`sc.physics.joint(type, a, b, x, y, length?, bx?, by?)` 创建距离、转轴或滑动关节。
两个实体必须有不同的刚体；锚点为世界像素坐标。容量 256，耗尽显式失败。
距离关节可提供独立的第二锚点 `bx/by`，否则两端使用 `x/y`。
转轴和滑动关节只有共同锚点，拒绝第二锚点参数。
滑动轴目前固定为 A 刚体的局部竖直轴。

```lua
-- 假设 anchor/body 已创建：锚点间距为 40 像素。
local rope = sc.physics.joint("distance", anchor, body, 85, 85, 40, 125, 85)
sc.physics.joint_control(rope, {
    limit = true, lower = 20, upper = 60,
    motor = true, speed = 48, max_effort = 100,
})
-- 反转电机，其余字段保持原值。
sc.physics.joint_control(rope, {speed = -48})
local controls = sc.physics.joint_control(rope) -- 返回独立副本
```

`joint_control(id[, patch])` 返回全部六个控制字段；patch 只允许下表字段。
所有字段和组合校验成功后才提交，错误不部分修改控制参数。
相同配置不重复重置约束或唤醒身体；改变配置唤醒连接的身体。
补丁类型为 `ScJointControlPatch`，所有字段可省略，省略表示保留当前值；
返回类型 `ScJointControl` 的六个字段始终齐全。nil 补丁为读取，空表为不修改。
参数严格检查数量和类型，不接受字符串形式的句柄、额外参数或带 NUL 的类型名。

| 字段 | 范围与单位 | 初始值 |
| --- | --- | --- |
| `limit` | boolean | 滑动为 true，其余 false |
| `motor` | boolean | false |
| `lower` | 距离 .16..4096 像素；滑动 -4096..4096 像素；转轴 -π..π 弧度 | 距离 .16，滑动 0，转轴 -π |
| `upper` | 同 lower，始终要求 lower ≤ upper | 距离 4096，滑动 length，转轴 π |
| `speed` | -1e6..1e6；距离/滑动为像素每秒，转轴为弧度每秒 | 0 |
| `max_effort` | 0..1e9；距离/滑动为质量×像素/秒²，转轴为质量×像素²/秒² | 0 |

所有数值必须有限；关闭限位也要求上下界有效。`motor=true` 且 `max_effort=0`
不会产生驱动力。距离关节速度的正方向为拉长，滑动为 A 的局部 +Y，转轴为
B 相对 A 的正角方向。角度使用引擎的 +Y 向下坐标约定。
转轴限位使用 B 与 A 的相对角，参考角为 0。

创建参数 `length` 为 .01..4096 像素，默认 8。距离关节实际最小静止长度 .16 像素，
对应当前 Box2D 稳定长度下限。未启用距离电机或限位时，它保持创建时的静止长度；
启用后使用无弹簧刚度的伸缩模式。距离 `lower=upper` 且启用限位时锁定该长度，
关闭电机和限位后恢复原静止长度。此接口不提供弹簧频率或阻尼调节。

限位是物理约束，允许求解器容差与受力变形，不是坐标硬截断。应按质量和速度
配置电机力；极大驱动力可能使位置明显超出名义限位。不能把这些约束当作地图
加载边界或安全范围检查。关闭电机不清除身体已有速度。

控制读写及销毁会同步待处理刚体修改，不推进物理帧，仅允许 load/init/update。
销毁实体、重建身体或切换房间会使旧关节句柄失效，不持久化关节句柄。
原生类型为 `ScJointId`（uint64），编码包含 20 位房间号、24 位生成号、8 位槽位，
最大 `2^52-1`，可在 Lua 整数和 JSON 数字中无损表示。新房间即使复用同一个槽位，
也拒绝旧房间的控制读取、修改和销毁请求。
房间重建时由 Lua 根据对象持久 ID 重新连接刚体。达到句柄生成号上限的槽位退休，
不回绕复用旧句柄。
