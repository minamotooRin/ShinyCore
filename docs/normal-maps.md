# 法线贴图

`SHINY_ADVANCED_RENDER=ON` 提供 `normal_maps` 能力。初始化时绑定两张同尺寸的
已声明 PNG 资源；普通运行不读取编辑工程或生成贴图。

```lua
-- load/init；名称来自 project.resources，路径可独立调整。
sc.lighting.normal("atlas","atlas_normals")
-- draw；height 只影响法线漫反射，不改变二维遮挡轮廓。
sc.lighting.point{x=160,y=80,radius=240,height=48,color="#FFE7BF"}
```

绑定按解析后的图像路径匹配，资源别名共享同一绑定。同路径重复绑定替换原记录，
未知资源或尺寸不匹配不改变旧记录。最多 64 组，只能在 load/init 配置；房间重建时
释放，不存入存档。它们仍受总纹理缓存容量约束，不额外提供 64 个 GPU 图像槽。

世界图像命令、实体精灵帧和 Tiled 图块使用同一关系；流式地图通过 sc.image 绘制
时同样适用。图集区域沿用颜色图的 UV，翻转、对角交换和精灵旋转同时变换法线 XY。
非均匀缩放不重新塑造表面凹凸。RGB 从 [0,1] 解码为 [-1,1]：+X 向右，+Y 向下，
+Z 朝向观察者；需要反向绿色通道的素材应离线转换。法线图 alpha 不参与计算。

启用绑定后，渲染器按现有世界绘制顺序生成一个逻辑画布尺寸的 RGBA8 法线目标。
颜色图 alpha 与绘制 tint alpha 决定表面覆盖；普通图像、文字和几何也覆盖下层
法线，使后绘制的无贴图表面保持原有平面照明。半透明交叠采用方向混合近似，
不是逐透明层的独立光照。自定义材质若改变颜色图 alpha 或执行 discard，法线覆盖
仍依据原始颜色图 alpha；不执行两次任意材质着色器来推断覆盖。

每个光源继续使用原投影轮廓和距离衰减，再乘以法线与光源方向的漫反射因子。
point.height 默认为 32，范围 0.001..4096 像素；实体 glow 使用默认高度。环境光
不受法线方向影响。未绑定法线的表面保持原有光照；屏幕 UI、当前在光照后合成的
弹体和粒子不使用该法线路径。后处理仍在世界合成后执行。

候选房间先创建目标并编译两个内置 GLSL 330 程序，全部成功后才提交，失败保留
活动房间资源。法线目标无深度和 mipmap，颜色预算 64 MiB；无绑定不创建目标或
内置法线程序。`sc.lighting.stats()` 提供 normal_maps、normal_capacity=64、
normal_target_bytes 和 normal_budget_bytes；字节数是颜色纹理逻辑大小，不是实测
VRAM，也不含图像资源、基础目标和后处理。无窗口实际分配字节为零。
